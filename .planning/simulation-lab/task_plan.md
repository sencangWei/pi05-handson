# MuJoCo 本地操作面板

目标：一次启动后在窗口选择布局、调整碗的 X/Y 位置、重置、运行/暂停/单步、保存视频与操作记录。用户亲自运行真实仿真；代理只做静态、隔离逻辑及无仿真 UI 检查。

- [x] 核对依赖与 env/native viewer 生命周期。Tk9 可用；重置须重建 viewer，避免旧模型指针。
- [x] 新增独立控制器和 Tk 面板，复用原模型动作契约与任务，不改训练、基准评测入口。
- [x] 验证重置/保存/断连/退出/位置修改边界与每步新观测；测试图形控件，明确不是真实策略演示。
- [x] 文档、记录、提交到可写远端并恢复比对。

边界：未实现示范数据采集或遥操作；本面板实验不混入正式基准成功率；没有自动松爪/撤手脚本。
