状态：数据、读取器和启动配置预检查通过（129个边界动作窗口，1046帧人工状态/动作逐项一致）。训练由学习者在中文面板点击开始，本次准备不启动训练、不停止模型。

## 本轮数据

- 新完整示范：human_1792404996662425932和human_1792405753674636144。
- 新250/340步记录和其它旧记录、草稿均保留原件；本轮不全量混入。两条新纠正候选须进一步选连续片段，未删除或否定其后续用途。
- 不抽帧拼接、不直接放大动作标签、不把视频加速当成更快的训练示范。导出名义时间索引10Hz，实际人工控制20Hz，每个原动作仍是一条训练记录，10步窗口来自相邻真实动作。

## 面板操作

1. 打开“模型与训练”，点击“刷新数据集”。
2. 选择文件名为 `corrections-public37_manual_tempo_pilot_v1-manifest.json` 的训练数据集。
3. 继续训练起点选择 `my_first_200/9999`（人工纠错前的公开数据10000步版本）。
4. 更新次数2000，batch=4，学习率1e-5，采样“均匀”。
5. 点击“开始训练”。面板会归档场景，停止它拥有的当前课程模型以释放显存，并启动独立训练；其它GPU任务不受操作影响。

父模型选择用来检验数据整理方案，避免在多轮实验模型上继续累积不可分离的变化；这不保证优于当前模型。先做2000步有界试验，batch4即总计8000个动作窗口，按实际数据均匀抽样；不是2000轮。1e-5是保守微调起点，效果需评测，不因loss下降就继续加步。

## 训练后

对比父模型、当前negative_quadrants实验版、新候选；固定相同初态、种子0/1、replan=1、800步预算。已录制位置属于训练位置诊断，另选未用于训练的位置检验泛化。首次On后继续50控制步，分别统计放置、实际松爪、稳定性、搬运速度、停滞次数、实际耗时。没有同预算对照或多种子证据时，不宣称数据修复具有确定因果效果。
