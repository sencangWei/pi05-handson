# 人工采集：普通/精细平移（2026-10-19）

已完成采集工具修改、真实物理校准、实际GUI录制检查并打开新版。此次没有重新训练或修改模型动作，没有重写已有示范。当前模型仍是negative_quadrants_20261019/1999实验版，行为可靠性不因采集工具修改而自动提高。

## 现在怎么录

1. 新版已打开“人工纠正”页，保留最后布局24和碗偏移X≈+7.94cm/Y≈+5.32cm，0步暂停，尚未接管。当前位置属于已发现困难/视野边缘场景，不保证模型能够完成；如采正常成功示范，可在“仿真操作”页先选择合适位置。
2. 点击“开始人工接管”。普通移动默认平移幅度0.6，用于空中接近、抬离后的搬运；靠近碗口、盘子、接触和重新夹取时切“精细移动”0.1。屏幕摇杆仍能通过拖动距离调节幅度。
3. 旋转按钮固定0.1；平移幅度数值只作用于XYZ和摇杆，不再同时放大旋转。夹爪开/闭与保持仍各10控制步。
4. “按钮连续步数”默认5，表示同一动作重复5次，不能当作速度档位。切档会停止正按住的摇杆，不推进物理或写新帧，需再次按住拖动。
5. 放稳→松爪→撤手至少10cm→保持10步，检查后保存合格；失败或无用尝试存草稿。建议先录一条完整的正常接近、抓取、搬运、放置供复查，再补困难位置。原批准纠错继续保留，不要求全部重录。

0.6/0.1是**归一化OSC控制幅度，不是米、厘米或直接速度值**。平移允许0.05–0.8，底层旋转接口仍限0.05–0.3；UI旋转固定0.1。普通档不是自动避碰控制，遇接触仍由操作者使用精细档。

## 实际校准，不是加速视频

在独立离屏MuJoCo、相同恢复初态/控制器下，对0.1、0.3、0.6各执行10步。空载六个XYZ正负方向，两个保存持碗状态各X/Y正负及Z向上，共48分支、480控制步。全程0次模型推理，未加入训练集。

| 状态 | 精细0.1：10步净位移 | 普通0.6：10步净位移 | 对应分支位移比 |
| --- | ---: | ---: | ---: |
| 空载 | 10.0–11.7mm | 62.6–72.9mm | 6.11–6.35倍 |
| 持碗008 | 9.8–11.9mm | 59.1–69.2mm | 5.80–6.57倍 |
| 持碗009 | 10.2–11.6mm | 60.4–69.2mm | 5.94–6.52倍 |

实际控制dt=.05s，10步对应0.5秒仿真时间。普通档比旧默认小步明确快；不是保证恒定6倍、不是界面墙钟速度或模型任务完成速度。

持碗普通档的碗-末端相对漂移最大：008约2.20mm、009约5.55mm；此短检查未见明显脱离，但不能称为零滑移或已认证所有抓取稳定。未测持碗向下接触、桌边、大角度旋转或全程收尾，接触阶段应使用精细档。完整逐步数据见calibration.json，代码calibrate.py；它仅是外部诊断控制，不是VLA恢复或人工批准示范。
