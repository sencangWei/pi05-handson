# 普通搬运与精细操作：分阶段抽样试验 v1

状态：**READY，尚未开始训练，尚无速度改善结果。** 用户要求普通移动要快，抓取、靠近盘子、放置和松爪可以慢；复用已有示范，减少重新录制。

## 实际改了什么

原 reviewed19_v4 的 56 段/13521 帧 parquet、动作标签、两路图像和 10 步动作窗口均不变。只新增固定的训练起点抽样配置：

| 来源/阶段 | 不同真实起点 | 20万虚拟索引中的数量 | 概率 |
|---|---:|---:|---:|
| 公开完整示范 | 4400 | 140000 | 70% |
| 原先批准的5个人工纠错片段 | 1066 | 20000 | 10% |
| 新人工接近、抓放、撤离及其他保留动作 | 6794 | 38000 | 19% |
| 明确的普通持碗搬运中段 | 1261 | 2000 | 1% |

人工合计从均匀按帧采样的67.46%降到30%，仍保留17个批准原始来源展开的全部19个人工片段。草稿排除，原件不动。新配置没有把动作乘倍数、加快视频、抽帧拼接轨迹或改变控制增益。

这是虚拟索引池的精确比例；有限训练时只近似这些比例。每个真实起点都在池中，不表示5000×4次取样一定遍历所有真实起点。增加公开示范占比也会减少一部分人工场景在固定预算内的曝光，须检查恢复能力有没有下降。

最初候选5%搬运/15%其他新人工被否掉：实际搬运起点少，5%会使每个搬运起点平均权重反而高于其他新人工。最终1%/19%对应平均重复权重1.586/5.593，即搬运约为其他新人工的0.284倍。`human-phase-audit.json` 中的5%/15%是保留的候选历史，现行配置以 `../phase-tempo-v1-selection.json` 和 `../phase-tempo-v1-profile.json` 为准。

## 阶段如何识别

只在新14段中，保守标出“闭爪后碗连续5帧比原桌面碗高至少4cm，再保护20步抓稳抬离，直到连续接近最终落盘XY6cm前”的中段，并避开全部开闭爪切换前后30步。最终落盘位置仅用于离线整理，未加入策略输入或在线控制。

得到10段连续搬运候选、1351个原始帧。每段末尾额外9个起点保留高一级权重，确保被降权的起点之后整个10步动作窗口都仍在该搬运中段内；因此实际低权起点1261个。

根代理查看了10段首尾的双RGB画面，确认是持碗移动；没有逐帧观看所有视频。原始范围、事件和哈希见 `human-phase-audit.json`。阶段判据偏保守：低位搬运可能仍留在“其他”，这个组不能全部称为精细接触或恢复。最后3段近盘放置没有当作普通搬运降权。`human_1792321044770146509 [478,510)` 的迟开爪/额外下压仍保留，现阶段不声称已解决所有释放标签问题。

## 训练后验收

对照父模型、上一轮均匀4999和本次1000/4999。固定seed42、replan1、相同800步预算、相同初始状态0–3及10–13；观察收尾时必须明确配置足够的post-success步数，不能首次On就结束。交互偏移场景init24、dx=0.06384364820846905、dy=0.1单列复现。

分别记录普通搬运的相邻新鲜观测每步位移、总控制步数、墙钟耗时、On、稳定开爪、撤手以及开闭反复次数。比较同一操作阶段，避免把贴近碗/盘子的精细慢动作也判失败。运行之间重启独立策略以固定采样RNG起点，保留失败和新输出目录。仅在搬运变快且抓取、放置和恢复不退化时接受新模型；小样本结果不称为广泛泛化。
