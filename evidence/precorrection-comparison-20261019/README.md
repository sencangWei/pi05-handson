# 人工纠错前模型与当前模型：同场景对照（2026-10-19）

## 结论

12次真实配对仿真全部完成并通过身份/输入/计分检查。较早模型严格完成1/6，当前模型3/6。当前模型部分完成能力更好，但接近仍明显慢、远端仍不可靠。**不能把全部问题归为“人工数据把原模型训坏”，也不能将当前模型称为已经修好。**

本次只对照，没有重新训练、替换8755模型或操作当前GUI。全部失败保留，没有按成功样本挑录像。

## 模型与实验约束

- 原模型：my_first_200/9999，最初16条公开示范后完成10000次更新的任务模型，人工纠错之前；不是未经训练的官方π0.5基座。
- 当前模型：negative_quadrants_20261019/1999，在多轮人工/公开/离线teacher微调之后。
- 同3个保存初态、策略seed0/1，每模型6次；相同初态积分状态和两路初始RGB全部逐元素相同。
- 归一化SHA一致；pi05条件仍为RGB+语言，state token关闭；预测10步，每次只执行第1步，最多800控制步。
- 严格完成：首次连续10步On+开爪命令+实际间距≥6cm+末端离碗≥10cm，再执行50步模型动作，期间条件持续成立且碗漂移≤5mm。数字包含这50步；不是只看On。
- 使用独立8756诊断服务，每个连接重置该模型采样RNG。相同seed是相同起始噪声流，不意味着不同模型后续画面/请求数量相同；也不复制GUI跨轮推进的RNG。

## 对下一轮的建议

保留已批准人工纠错和当前模型，不把旧模型直接切回“可靠版”。重训之前，先按接近、普通搬运、抓放接触、失败恢复分开审查有效标签及覆盖，尤其是最新远负/视野边缘的连续成功路径。抓放可以慢，普通搬运需要真实较快的连续数据；不能只改视频倍率、把动作乘倍数或拼不连续窗口。下一轮若要分离数据因素，应从同一父模型、相同预算做原数据与整理数据的对照，另设未用于采集/调参的新位置。此次没有自动启动重训。
