## 人工纠正复核与补录

本地复核页：`.local/correction-review-20261018-v2/index.html`，包含两路相机完整录像、关键帧与开合阶段。录像为录制动作的回放，不是新模型评测。图像对应动作执行前，On标注对应动作执行后。播放器按名义10帧/秒显示，实际仿真控制周期另记为0.05秒；人工停顿不在视频内。

按连续片段检查：正确脱离卡住状态 → 抬起 → 重新对准 → 放稳 → 松爪 → 撤手。记录起止帧、纠正类型和是否存在错误动作；不把停留很久或持续闭爪直接判为坏数据。复核工具不自动裁剪或重新标成专家。原件始终保留，复核后再建立新版本。

补录至少覆盖三类：抓空/夹住碗边后重抓、碗滑动后的重新定位、放偏后的抬起重放。每类先在不同位置录多条短而清楚的成功纠正；留出单独的场景偏移用于评估，相同scenario_key不跨训练与留出。数量只作采集预算，最终依据独立仿真表现决定是否足够。新采集不得混入下面预先固定的评测场景。

## 固定评测

评测方案：`evidence/coverage-v2-evaluation-plan.json`。正常/位置偏移/恢复分别计数，对照旧父模型与新模型；每轮记录模型指纹、种子、初始状态哈希、动作、录像和异常。

公开示范主要提供成功行为，增加它们可以扩展正常任务覆盖；失败恢复仍需要对应示范和单独评测。本次准备完成不代表新模型已训练或已获得恢复能力。
