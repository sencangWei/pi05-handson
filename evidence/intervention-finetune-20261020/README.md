## 对比协议

4个真实人工接管物理状态、2个旧开发控制场景，每个2个种子；前后各12次。每次最多600步，replan=1；连续10步放置、开爪、实际指间距>=6cm、末端距碗>=10cm后，再运行50步。严格通过还要求后50步门持续通过且碗漂移<=5mm。单次On不直接记为严格成功。

接管现场本身用于训练，旧控制也已用于开发，所有数字均为小规模开发诊断，不能称独立泛化成功率。物理状态哈希精确复原；控制器隐藏状态使用现有方法重建，不是原GUI逐位续跑。四个接管场景首帧8维观测与原记录最大误差<1e-6。

训练前12次已跑完：严格通过2/12，接管现场0/8，旧控制2/4。部分碗已放稳但手部后续不满足严格门，另有未放下情况；不把这些混为同一种故障。
